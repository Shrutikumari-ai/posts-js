# 📌 Posts Data Fetch App

A simple and responsive web application that fetches post data from the
DummyJSON API and displays it in responsive cards using HTML, CSS, and JavaScript.

---

## ✨ Features

- Fetch data from DummyJSON API
- Display posts dynamically
- Responsive design for all devices
- CSS Grid Layout
- Modern Card UI
- Hover Effects
- Async/Await
- Error Handling

---

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript (ES6)
- Fetch API
- Async/Await

---

## 📡 API Used

https://dummyjson.com/posts

---

## 📷 Project Preview

Displays:

- Post ID
- Post Title
- Post Description
- Views
- Likes
- Dislikes
- Tags

## ▶️ How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Run `index.html` using Live Server.
4. The application will automatically fetch and display posts.
